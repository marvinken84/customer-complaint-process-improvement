# Customer Complaint Process Improvement

## Business Analysis & Six Sigma Portfolio Project

### Project Overview

This simulated portfolio project analyzes a customer complaint-resolution process for a fictional online retail company.

The objective is to identify process bottlenecks, analyze stakeholder needs, define business requirements, propose an improved process, and establish measurable KPIs.

The project demonstrates practical application of:

- Business Analysis
- Stakeholder Analysis
- Process Mapping
- Requirements Analysis
- Six Sigma DMAIC
- Process Improvement
- KPI Development
- Problem Solving

> **Disclaimer:** This is a simulated portfolio project. The company, performance figures, and scenarios are fictional and are used for educational and portfolio purposes.

---

## Business Problem

The fictional company is experiencing delays in responding to and resolving customer complaints.

The simulated baseline performance includes:

- Average first response: 18 hours
- Average resolution time: 4.8 days
- Complaints resolved within 48 hours: 42%
- Customer satisfaction: 68%
- Complaints unresolved after 7 days: 15%

These figures are simulated for the purpose of demonstrating the analysis process.

---

## Project Objectives

The project aims to:

1. Understand the current complaint-resolution process.
2. Identify process bottlenecks and potential causes of delays.
3. Identify and analyze key stakeholders.
4. Define functional and non-functional requirements.
5. Design an improved future-state process.
6. Establish KPIs to measure performance.
7. Apply the Six Sigma DMAIC framework.

## Key Process Problems

The analysis identified several potential problems:

- Manual complaint assignment
- Lack of automatic escalation
- Limited management visibility
- Repeated requests for customer information

These issues may contribute to longer resolution times and reduced customer satisfaction.

---

## Proposed Future-State Process

The proposed process introduces:

- Automatic complaint confirmation
- Complaint categorization
- Automatic assignment
- Complaint status tracking
- Escalation of overdue complaints
- Management visibility
- Customer satisfaction measurement
